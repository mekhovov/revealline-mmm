# Illustrated Equipment Workshop sources

This source directory supports the proposed **Equipment Workshop 1.1.0** picture edition for working RevealLine v0.17.0. Three original PNGs add collectible pictures to the existing Garden of Threads, Neon Switchboard and Clear Ledger maps. A successful builder check establishes source/embedding consistency and image-header validity; it does not establish browser decoding, composition quality or a verified release.

The preserved [previous edition](previous/equipment-workshop-1.0.0.json) is the exact procedural v1.0.0 pack: **18,389 bytes**, SHA-256 `91876d315417252a65a36b1a46f3f3e03737ec26ccc08224f52e9c376f76ea1a`. Its bytes were compared with the independently frozen v0.16.0 distribution, source commit `8fb6b5782a6fee85211b9bbbfb3d13a1d1a60c43`, before creating this baseline. Preserve this file byte-for-byte; do not format or regenerate it.

[pack-source.json](pack-source.json) changes only pack semver to `1.1.0` and retains empty generated `levelVisuals`. The complete campaign, normalized maps, seven recipes, themes, music and three optional goal definitions remain unchanged. The builder enforces this against the exact preserved baseline. New image names/descriptions are presentation sidecars, not changes to map metadata. The campaign identity remains `equipment-workshop/1/3fc2cf073da368b4`; integration checks must verify existing saves, scores, pictures and seals against the installed new edition.

## Check or deliberately rebuild

Run from the repository root, using the repository's supported Node runtime:

```sh
node scripts/build-workshop-pack.mjs
node scripts/build-workshop-pack.mjs --write
node scripts/build-workshop-pack.mjs
node --test scripts/test-build-workshop-pack.mjs
```

The first/default command is **read-only** and reports missing or stale generated content. After reviewing the source and images, explicit `--write` atomically replaces only `game/content/packs/equipment-workshop.json`; it never writes the PNGs, provenance, baseline or source recipe. Invalid inputs leave the previous generated pack in place. A normal formatting-only change to generated JSON can pass the default semantic comparison; embedded image bytes must still match exactly. Only the optional `--write` CLI flag is accepted.

`buildWorkshopPack({root, write = false})` returns `{pack, report}` for trusted local tooling. The injectable root supports isolated tests. Fixed file paths, regular-directory/file checks, bounded reads and source comparisons prevent an image or output symlink from redirecting normal operations. This local builder is not a multiwriter authoring service; do not edit its selected sources during a build. The tests use temporary copies of these actual selected Workshop PNGs for exact embedding, filesystem and semantic rejection cases; they do not certify browser decoding. Header mutations exist only as rejected temporary metadata fixtures.

Keep the [Homeward builder](../../../scripts/build-homeward-pack.mjs), its source PNGs/generated pack and all existing replay proof bytes unchanged. This art-only update needs no discovery or recording command. Runtime pack validation/build already discovers the same indexed Workshop path. Follow [authored art](../../../docs/authored-art.md) for public pack import/export and [the Workshop guide](../../../docs/equipment-workshop.md) for its established equipment routes. Returning collected pictures deliberately resolve to the currently installed art edition; installing art does not itself award another clear, score or seal.
