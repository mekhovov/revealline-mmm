Company edition review

Observe a real company game on this server. Compare a frozen baseline with the candidate on the same device and browser. This tool never drives the game, changes its state or sends telemetry. The game uses its normal saves.

Choose a baseline or candidate, then load it.

Intervals measure browser animation callbacks, including observer overhead, rather than game render duration. Resource totals include only buffered Resource Timing entries; zero transfer may reflect caching or unavailable timing details. Hidden, paused or interrupted samples are discarded. Heap size is reported only where the browser exposes its approximate, process-shared metric; it is not proof of a memory leak or its absence. No result automatically approves a release. Current Solo builds measure activation until a running flight is observed; historical company builds measure until their explicit start is ready. Those two preparation endpoints must not be compared as the same metric. Choose the scenario that is actually visible before starting a sample. The session summary counts ready target transitions; it does not prove installed-app isolation, preserved storage or physical-device performance.
