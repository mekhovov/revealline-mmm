# Historical publication records

These nine exact originals preserve six earlier Coupa capacity manifests and three published community entry pages. They are archival evidence, not inputs to the playable app. Their source identities and checksums are recorded in `migration/recovery-publication-originals-receipt.json`.

The generated application continues to use only its configured Capture and Snake content. Archived entry pages and manifest references must never be served as runtime routes or used to enable other game families.
